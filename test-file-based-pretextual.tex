\chapter{Introdução}

Este é um teste do sistema de páginas pré-textuais usando arquivos externos. 
O sistema deve automaticamente incluir os arquivos da pasta tex/ e formatá-los 
corretamente com os ambientes apropriados.

\section{Funcionalidades Testadas}

\begin{itemize}
\item Ambiente dedicatória com formatação específica
\item Ambiente agradecimentos com formatação adequada
\item Ambiente resumo com palavras-chave automáticas
\item Ambiente abstract com keywords automáticas
\item Integração com sistema de numeração romana
\item Inclusão automática de arquivos tex/
\end{itemize}
