\chapter{Introdução}

Este é um teste para verificar se o sistema de páginas pré-textuais opcionais 
funciona corretamente para documentos de qualificação.

Para qualificação, o sistema deve:
\begin{itemize}
\item Omitir dedicatória e agradecimentos
\item Incluir apenas resumo e abstract
\item Manter a numeração romana correta
\end{itemize}
